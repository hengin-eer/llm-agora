## プロジェクトの概要
LLM Agoraは自律的に合議進行を行うAIエージェントです。
特徴としては以下のようなものが挙げられます。
- ロールを切り替えながら議論進行を行う
  - 疑似的に複数のAIエージェントが協働しているようになっているが、実際には一つのAIエージェントがロールを切り替えながら議論を進行している
- ユーザは議論をシステムに与えることで段階的に合議の出力が行われ、議論過程を観察することが出来る
- 合議が終了次第、履歴が保存されユーザはいつでも過去の議論を振り返ることが出来る

本研究ではこのエージェントを用いて、合意形成を行う際の傾向をアーキテクチャや与えるロールを変化させながら探ることによって、汎用的に理論化できないか、ということを目指しています。
