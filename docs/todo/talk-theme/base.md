# 多面的議論テーマ選定基準 (Base Criteria)

**作成日**: 2025年12月15日
**目的**: 「多面的議論モード（Multifaceted Debate Mode）」の効果を最大限に引き出し、自律型AIエージェントによる合議の質を評価・向上させるためのテーマ選定基準を定める。

---

## 1. 基本方針

従来の「肯定 vs 否定」の二元論で完結してしまう単純なテーマではなく、**「正解のない問い」**や**「トレードオフが複雑な問題」**を選定する。
これにより、批判的思考者（Critical Thinker）、創造的思考者（Creative Thinker）、調停者（Mediator）といった拡張ロールが機能する余地を作る。
**ロールごとに長所、短所がはっきり分かるようなテーマを意識する**。

## 2. 選定基準 (Criteria)

### A. 多義性・曖昧性 (Ambiguity)
- 単純な事実確認や、データだけで白黒つく問題は避ける。
- 定義そのものが議論の対象となるようなテーマ。
- *例: 「幸福とは何か？」「真の豊かさとは？」*

### B. 利害関係の複雑さ (Multi-stakeholder Complexity)
- 2つの対立軸だけでなく、3つ以上の異なる立場や利害が絡む問題。
- 「あちらを立てればこちらが立たず」という状況が含まれるもの。
- *例: 都市開発における「経済発展」「環境保護」「住民の生活」「観光客の利便性」のバランス。*

### C. 倫理的ジレンマ (Ethical Dilemma)
- 功利主義的な正解と、義務論的な正解が対立するような問題。
- 技術的解決だけでなく、価値観のすり合わせが必要なもの。
- *例: 自動運転車のトロッコ問題、遺伝子編集の許容範囲。*

### D. 未来志向・創造性 (Future-oriented / Creativity)
- 現状の延長線上にはない、飛躍したアイデアやSF的思考が求められるテーマ。
- 「どうあるべきか（Normative）」だけでなく「どうありうるか（Speculative）」を問うもの。
- *例: 人類が宇宙に移住した後の社会契約、AIが労働を代替した後の人間の役割。*

## 3. ロールごとの期待値

テーマ選定時は、各ロールが以下のように活躍できるかをシミュレーションする。

- **批判的思考者**: 前提条件（「そもそもそれは技術的に可能なのか？」「コストは無視していないか？」）を攻撃できるか？
- **創造的思考者**: 既存の対立軸（A案 vs B案）を飛び越える「C案（ウルトラC）」を提案する余地があるか？
- **調停者**: 対立する意見の中に、共通の価値観や妥協点を見出せるか？

---

## 4. テーマの形式

議論を開始する際のプロンプト（議題）は、以下の形式を推奨する。

1. **オープンクエスチョン型**: 「〜についてどう思うか？」ではなく「〜を解決するための最適なアプローチは何か？」
2. **シナリオ設定型**: 具体的な架空の状況設定を与え、その中での意思決定を求める。
3. **制約条件付き**: 「予算無制限なら」「100年後の視点で」などの制約や視点を付与する。
