## フェーズ2: 議論機能の拡張

- [ ] **議論の一時停止/再開**

  - 状態の保持


- [ ] **追加ロール**

## 優先度メモ

| 優先度 | 機能 | 理由 |
|--------|------|------|
| 高 | マークダウンプレビュー | 可読性向上 |
| 高 | チャットUI改善 | UX向上 |
| 中 | ユーザー割り込み機能 | 仕様の核心 |
| 中 | 議論ログの保存 | 研究用途 |
| 低 | 複数モデル対応 | 拡張機能 |
